# Security policy

`tinydigit` reads PGM files that may come from anywhere. A file that makes it crash, read or write out of bounds, hang, or behave differently from what the README describes is a security issue.

Please report it privately through GitHub's **Report a vulnerability** button on the repository's Security tab (https://github.com/Mersbyte/tinydigit/security/advisories/new), not in a public issue. A small PGM file that shows the problem helps most.

Only the latest commit on `main` is supported.
